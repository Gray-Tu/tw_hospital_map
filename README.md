# 台灣醫院經營版圖 tw_hospital_map

**線上版：https://gray-tu.github.io/tw_hospital_map/**

把全台健保特約醫院攤在地圖上，重點不是「哪裡有醫院」，而是**每家醫院背後是誰在經營**——
哪些是財團、哪些是宗教團體、哪些是大學體系、哪些公立醫院其實委外給民間集團經營，
以及各體系在台灣的布點策略與醫療特色。

## 成果

- `web/` — 可直接開啟的地圖式 Web UI（底圖只畫台灣縣市界，不載入外部街道圖磚）：點選任一醫院即顯示其經營體系、背後出資主體、
  公辦民營關係、醫療特色與科別；點選左側體系可看該集團的完整版圖（縣市布點、層級組成、院所清單）。
- `data/groups.json` — 83 個經營體系的人工彙整對照表（法人主體、背後財團／教會／政府、創立年、官網）。
- `data/hospital_sites.json` — 132 家醫院的官方網站（每一個網址都實際連線驗證過）。
- `data/processed/hospitals_geo.json` — 每家醫院的正規化資料 ＋ 集團歸屬 ＋ 座標。

## 資料來源（政府權威資料）

| 資料 | 來源 | 說明 |
|---|---|---|
| 醫學中心名冊 | [data.gov.tw/dataset/39280](https://data.gov.tw/dataset/39280) | 衛福部中央健康保險署，每日更新 |
| 區域醫院名冊 | [data.gov.tw/dataset/39281](https://data.gov.tw/dataset/39281) | 同上 |
| 地區醫院名冊 | [data.gov.tw/dataset/39282](https://data.gov.tw/dataset/39282) | 同上 |
| 座標 | [OpenStreetMap Nominatim](https://nominatim.openstreetmap.org/) | 以院名／地址地理編碼 |
| 縣市界線 | [g0v/twgeojson](https://github.com/g0v/twgeojson)（內政部資料） | 地圖底圖，簡化後 144 KB |

健保署 CSV 欄位包含：醫事機構代碼、名稱、種類、電話、地址、分區業務組、特約類別、
服務項目、診療科別、終止合約或歇業日期、固定看診時段、備註、縣市別代碼、合約起日。

## 方法

1. **抓取**：三份健保署名冊（醫學中心／區域／地區醫院），共 488 筆。
2. **清理**：全形數字轉半形、拆出縣市與鄉鎮市區、濾掉「終止合約日期已過」的院所。
3. **判定經營體系**——本專案的核心。健保署登記的**院所全名帶有法人主體**，
   例如「長庚醫療財團法人林口長庚紀念醫院」「醫療財團法人徐元智先生醫藥基金會亞東紀念醫院」，
   因此以法人名稱正則比對 `data/groups.json` 的體系規則，再人工補上背後的財團／教會／家族。
   - **產權 vs 經營分離**：院名中的「委託 OO 經營／興建經營／辦理」會被單獨解析，
     區分 `owner_group`（設立主體，多為地方政府或衛福部）與 `operator_group`（實際經營團隊）。
     目前偵測到 14 件公辦民營案例（如新北市立土城醫院→長庚、臺南市立安南醫院→中國醫）。
   - 院名已不再標示委託字樣、但實際仍為委外經營者，以 `data/overrides.json` 人工修正。
4. **醫療特色標籤**：由「診療科別」與「服務項目」推導，例如有放射腫瘤科→癌症治療、
   有血液透析／腹膜透析→洗腎透析、有住院安寧療護→安寧療護。
5. **地理編碼**：以院名主體（去除法人前綴）查 Nominatim，每次取 5 筆候選，
   要求回傳地址的**縣市與鄉鎮市區都相符**才採用——這道把關擋掉了 22 家被比對到
   同縣市同名機構的錯誤定位。命中不了才逐級退回：
   院名 → 院名＋縣市 → 縣市＋區＋路名 → 結構化查詢（street+city）→ 區中心。
   最終 450 家全部定位，446 家達街道級以上，行政區不符 0 家。
6. **底圖**：不用 OSM 街道圖磚——那會把整片華南也畫進來、細節也蓋過資料點。
   改成只畫台灣 22 縣市界線：`scripts/build_geo.py` 以 Douglas-Peucker 把
   內政部縣市界從 9.3 MB／20.8 萬個節點簡化到 144 KB／7,741 個節點（保留澎湖、金門、馬祖），
   地圖範圍鎖在台灣、縮放上限收在縣市尺度。點縣市可直接篩選該縣市。
   金門與馬祖的真實位置離台灣太遠，會把整張圖拉得又寬又空，因此把兩縣**當剛體平移**
   到台灣西側的海域，外圍畫虛線框並標示縣名。南北順序維持真實關係（由南到北：澎湖 → 金門 → 馬祖）；
   金門真實緯度 24.39~24.53N 剛好落在澎湖與馬祖之間，所以只往東平移 1.5°、緯度完全不動；
   縣市界與醫院座標套用同一組位移以保持一致，真實座標保留在 `rlat`／`rlon`，
   醫院詳情頁會註明示意位置與實際經緯度。
7. **官網驗證**：`scripts/verify_sites.py` 逐一連線測試人工彙整的網址，
   403/405 視為「站台存在只是擋程式化請求」，其餘連不通者一律不寫入，
   同時清掉 `groups.json` 裡失效的體系官網——寧可留搜尋連結，也不放死連結。

## 執行

```bash
python scripts/build_geo.py        # 縣市界簡化 -> web/data/tw_counties.geojson
python scripts/build_dataset.py    # 原始 CSV -> data/processed/hospitals.json
python scripts/geocode.py          # 地理編碼（約 15-25 分鐘，結果有快取）
python scripts/export_web.py       # 打包成 web/data/app_data.json
python -m http.server 8765 --directory web
```

重新下載原始資料（Windows PowerShell）：見 `scripts/fetch_raw.ps1`。

## 部署

`web/` 是完全靜態的（885 KB），沒有後端、沒有建置步驟、執行期不呼叫任何外部服務——
Leaflet 已 vendor 進來，底圖是自家的縣市界 GeoJSON，所有路徑都是相對路徑，
因此放在網站根目錄或子目錄都能跑。

本專案以 `gh-pages` 分支發布，更新資料後重新部署：

```bash
python scripts/export_web.py
git add -A && git commit -m "更新資料"
git push origin main
git subtree push --prefix web origin gh-pages
```

換到其他靜態代管（Netlify／Cloudflare Pages／S3／內網 Nginx）時，
把 `web/` 當發布目錄即可，build command 留空。

## 已知限制

- **背後財團的認定屬公開資訊整理**，來自各體系官網沿革與公開報導，非官方登記文件；
  「背後主體」欄位僅供研究參考，不代表現行股權或董事會結構。
- 215 家醫院未隸屬於已彙整的體系，多為單一院區或家族經營，僅標示法人型態
  （單一財團法人／醫療社團法人／私人獨資）。
- 座標來自 OSM，4 家院所因登記地址本身沒有路名（如「嘉義縣朴子市永和里42-50號」）
  只能退回鄉鎮市區中心，UI 上會標註「非精確門牌座標」。
- 醫療特色標籤由健保署的科別與服務項目推導，屬於「有無提供該服務」而非品質評比；
  衛福部的「急救責任醫院能力分級（重度／中度／一般級）」目前僅以 PDF 公告發布，
  尚未納入，是後續可強化的方向。
- 只涵蓋**醫院**（醫學中心／區域／地區醫院），不含約 2 萬家診所。
- 地圖上金門、馬祖為縮短距離後的示意位置（虛線框內），不可用於量測距離或方位。
